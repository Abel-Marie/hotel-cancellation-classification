Will this booking be cancelled?

Describe a hotel booking as it looks on the day it is made, and a machine-learning model estimates the chance that it is cancelled before arrival. This is a student project built on public data from two hotels in Portugal, not a live hotel system.

What it deliberately ignores

Some columns in the hotels' records are filled in after the booking, often at check-in. Using them would make the model look far better in testing and fail in practice, so it never sees them.

Limits of this demo

  • It learned from two hotels in Portugal and may not transfer to other hotels, countries or years.
  • It scores bookings, not people, and should never be the only reason to refuse a guest.
  • In this data non-refundable bookings were cancelled far more often than others, so the model rates them high. That is a pattern of these records, not a rule about deposits.
  • The outcome buttons under each estimate are how a hotel would report what really happened; the summary shows how the model is doing on those reports.
